# Motion graphics

Use when a concept is better understood as a visual system than as a caption.

- Treat the graphic as its own full-screen mode, not as a white caption card.
- Establish the visual metaphor before adding details: for example, a California outline, a highlighted Silicon Valley region, a percentage count, then a clean company-logo row.
- Build in a clear order: base map/diagram → highlight → statistic → supporting marks. Avoid simultaneous movement everywhere.
- Logos should be optically balanced in a clean horizontal row; controlled overlap is acceptable when the brief calls for it, but spacing must remain readable.
- Keep the warm off-white, charcoal, and orange system so the graphic belongs to the Reel.
- Separate sourced facts from visual claims. If a statistic lacks reliable support, flag it in the brief and do not add a fake citation.
