# White editorial canvas with captions

Use for a text-led argument reset or a short authored statement on a warm off-white full frame.

- Keep the canvas warm off-white with charcoal type and restrained orange emphasis.
- Centre the text as one compact group. Explicitly control column/row spacing; never allow wrapped flex lines to stretch across the screen and create an accidental vertical gap.
- Use the approved editorial typeface and size tokens. The current reference treatment uses an italic serif for the statement card and clean sans-serif for ordinary captions; do not mix families without a reason.
- Reveal words or lines calmly and in sync with delivery.
- This mode is **caption-only**. Do not place maps, counters, diagrams, logo rows, charts, or other motion graphics here; route those to [`motion-graphics.md`](motion-graphics.md).
