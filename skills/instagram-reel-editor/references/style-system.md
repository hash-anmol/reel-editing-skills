# Instagram Reel style system

This is the shared contract across the visual modes. Treat it as a default, not a reason to add decoration.

## Base tokens

- Format: portrait 9:16 unless the brief explicitly says otherwise.
- Editorial canvas: warm off-white (`#f6f3ed`).
- Ink: charcoal/near-black (`#171513`).
- Accent: restrained orange (`#ff5a00`).
- Motion: calm, short blur-settle or vertical-slide entrances; no bouncing karaoke or generic sticker effects.
- Safe area: keep faces and captions clear of Instagram UI; use one caption geometry across the edit.
- Raw-media default: no border, shadow, radius treatment, label, or duplicate explanatory copy unless approved.

## Routing rule

Choose the least elaborate mode that makes the spoken idea clearer. The face remains the anchor when the argument benefits from intimacy; a media or graphic takes the frame only when it is the evidence. Do not introduce a new visual language for one asset.

## Source and transition rules

- Prefer exact, first-party proof over generic stock decoration.
- Use `object-fit: contain` when the whole image or product must be recognized; crop only with an explicit reason.
- Adjacent full-screen B-roll clips should be contiguous hard cuts unless the brief calls for a deliberate transition.
- Use posters or a ready first frame for timed video inserts so a render never shows a blank frame or a one-frame A-roll flash.
