# A-roll + media — minimal overlay

Use when the creator should remain present while a relevant image or video supplies proof.

- Keep the A-roll visible and face-safe.
- Place one media insert in the middle/lower third below the face, using the same geometry across beats.
- Default to raw media with no border, shadow, label, title strip, or duplicate caption. Add any of these only when the approved brief says why.
- Use the exact product, person, company, or action being discussed. Prefer a real presentation, build, demo, or launch moment over a generic logo/photo.
- Use `contain` when the supplied image must be fully visible; crop only to remove irrelevant baked bars or to preserve the subject.
- Mute external source audio unless the brief explicitly calls for it.
- Do not overlay authored text beneath a media insert just to name what the viewer can already see.
