SETUP GUIDE

Reel Editing Skills

Six agent skills for making Instagram Reels. Your agent plans the edit, cuts the footage, and finishes the piece. You make the calls. Setup takes about two minutes.

THE SIX SKILLS

grill-me-reel-edit
Interviews you about the hook, pacing, and the choices that actually change the edit, before anything gets cut.
create-reel-editing-brief
Turns the script and decisions into a production brief with a beat-by-beat edit map and the style rules.
reel-asset-board
Collects the assets the reel needs into one reviewable board. An approval gate before editing.
do-a-rough-cut
Transcribes every take, maps the repeats, keeps your one true script, assembles an ordered first cut.
do-a-fair-cut
The tight pass: clips start right after the previous spoken phrase, pauses removed, dead air machine-checked.
instagram-reel-editor
Builds the final reel in HyperFrames: captions, overlays, motion graphics, verified render.

INSTALL

STEP 01

Install HyperFrames first.

HyperFrames renders an edit into video, and the final step of the pipeline runs on it. Ask your agent:

"Install HyperFrames and set it up for video rendering."
STEP 02

Install the skills.

Ask your agent:

"Clone github.com/hash-anmol/reel-editing-skills and install all six skills."

Or by hand: copy the six folders from skills/ into your agent's skills directory, then start a new session so it sees them.

SET UP

  • ffmpeg and ffprobe on PATH. Both cutting skills run on them.
  • Node.js and HyperFrames. Only the final edit step needs these.
  • A transcriber. Whisper for clean English; a code-mix model for Hinglish (for example Sarvam saaras:v3, codemix mode).

HOW TO USE IT

  • Say what you want, not which tool: "Cut these four recordings into a tight Reel with no dead air, then build the final with captions." Your agent picks the right skill for each step.
  • You stay in control at the gates. The brief and the asset board are approval points, and your agent asks before irreversible choices. Reply with comments for another pass.
  • Renders are verified before they reach you: probed, fully decoded, checked. Watch it, comment, approve.

do-a-rough-cut → do-a-fair-cut → instagram-reel-editor

HyperFrames enters at the last step only, for captions, overlays, and motion graphics. The cuts before it are plain ffmpeg.

A QUICK EXAMPLE

You: "I recorded four takes of my reel. Rough-cut them, then make it tight."
Agent: asks about the hook and take choices, cuts, and shows you the render.
You: "Put the screen recording first."
Agent: takes another pass and shows you the new version.
